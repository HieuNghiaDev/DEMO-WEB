# Required document inspector — UI quality check

- The inspector uses the existing document-collection shell, typography, spacing, and light/dark tokens.
- The revised sequence follows the work itself: collection conditions, received documents, collection work, fulfillment and exceptions, then manager review.
- The manager-review area is a compact final step, not a separate dashboard card or promotional callout.
- No new gradient, decorative illustration, metric, or unrelated navigation was introduced.
- The layout remains a single inspector column at narrow widths; existing mobile rules retain one-column summaries and stacked controls.
