プライバシーポリシー

最終更新日：2026年10月6日

THEMISは、利用者の個人情報およびGoogleユーザーデータを 適切に取り扱い、安全に保護することを重要な責務と考えています。

1. 取得する情報

THEMISは、サービス提供のために以下の情報を取り扱う場合があります。

  • 利用者がシステムへ登録した社員情報および案件情報
  • Google Drive上の業務用ファイルおよびフォルダ情報
  • Google OAuthによって発行された認証トークン
  • システムの利用履歴およびセキュリティログ

2. Googleユーザーデータの利用目的

Google Driveへのアクセス権限は、利用者が明示的に許可した場合にのみ取得します。 取得したGoogleユーザーデータは、次の目的に限定して使用します。

  • 案件に関連する業務文書の取得および表示
  • 利用者が確定した文書のGoogle Driveへの保存
  • 案件、依頼者および文書フォルダの整理
  • Google Drive連携機能の維持および障害対応

3. 情報の共有

THEMISは、法令に基づく場合を除き、Googleユーザーデータを 第三者へ販売、貸与または広告目的で共有しません。

4. 情報の保存と保護

OAuth認証情報は、アクセス制限された環境変数または 非公開ストレージに保存されます。通信には暗号化されたHTTPS接続を使用し、 業務上必要な権限を持つ利用者のみが情報へアクセスできます。

5. 保存期間と削除

情報は業務上必要な期間のみ保存します。利用者はGoogleアカウントの セキュリティ設定から、いつでもTHEMISのアクセス権限を取り消すことができます。 削除に関する依頼は、下記の問い合わせ先へご連絡ください。

6. Google API Services User Data Policy

THEMISによるGoogle APIから取得した情報の利用および他のアプリへの転送は、 Limited Use要件を含む Google API Services User Data Policy に準拠します。
